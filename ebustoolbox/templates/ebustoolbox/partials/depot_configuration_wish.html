{% translate "Flächendetails" %}

Hier können Sie manuell die Flächen des Depots definieren. Die Kapazität entspricht der gesamten Anzahl an Ladeflächen für diesen Fahrzeugtyp. Ein Fahrzeugtyp kann nur eine Fläche nutzen und mehrere Fahrzeugtypen können sich keine Ladeflächen teilen. Sollten die Fläche ein Block bzw. Rechteck sein, wählen sie unter Anordnung 'Blockabstellung' aus. In diesem Fall wird der Rangiervorgang auf der Ladefläche berücksichtigt. Beachten Sie, dass die Mindeskapazität jeder einzelnen Fläche zwei betragen muss. Die Blocklänge gibt an, wieviele Busse hintereinander stehen und sich somit beim rangieren blockieren. Die Blocklänge muss nur angegeben werden wenn 'Blockabstellung' ausgewählt ist. In diesem Fall muss die Blocklänge ein ganzzahliger Teiler der Kapazität sein. Die Eingabemaske springt automatisch auf den nächstgelegenen erlaubten Wert, falls Sie einen nicht erlaubten Wert eingeben.
