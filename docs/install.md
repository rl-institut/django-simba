# Administration
WeBus ist Open Source und kann lokal ausgeführt werden.
Einige Einstellungen sind nur für Administratoren verfügbar und erlauben erweiterte Feature.

## Installation

WeBus ist für Linux entwickelt, doch auch auf macOS und Windows lauffähig.
Mithilfe von docker kann eine lokale Webseite in wenigen Schritten erzeugt werden.

### Docker
1. Installiere [git](https://git-scm.com/downloads)
2. Klone das Repo in einem Verzeichnis Ihrer Wahl
```bash
git clone https://github.com/rl-institut/django-simba.git
```
3. Installiere [Docker](https://docs.docker.com/engine/install/)
4. Navigiere in das geklonte Repo
```bash
cd django-simba
```
5. Erzeuge eine Datei ".env" mit folgendem Inhalt. Diese ist für eine lokale Entwicklungsumgebung und nicht fürs öffentliche Hosten geeignet.
```env
     # Sicherheitsschlüssel für die Verschlüsselung
     DJANGO_SECRET_KEY=INSERT_YOUR_KEY_HERE
     DJANGO_DEBUG=True
     # Replace with your own database info
     DATABASE_URL=postgis://myprojectuser:1234@my-docker-postgres:5432/mydb
     CELERY_BROKER_URL=redis://my-docker-redis:6379/0
     CELERY_TASK_ALWAYS_EAGER=False
     TILING_SERVICE_TOKEN=GET_YOUR_TOKEN_THROUGH_MAP_TILER
     TILING_SERVICE_STYLE_ID=basic-v2
     DJANGO_SETTINGS_MODULE=ebusdjango.settings
     # If you are developing locally set this to true. It disables production security features.
     DJANGO_LOCAL_DEVELOPMENT=True
     # for elevation API usage
     DJANGO_ELEVATION_TOKEN=YOUR_TOKEN_ELEVATION_TOKEN
     OPENELEVATION_URL=http://127.0.0.1:8000/elevation_api/YOUR_TOKEN_ELEVATION_TOKEN
     # If no admin user exists in the database, one will be autogenerated with this password
      DJANGO_ADMIN_PASSWORD=SOME_ADMIN_PASSWORD
```
6. Führe folgenden Befehl aus um den Server auf Windows oder macOS zu starten.
```bash
docker compose up
```
oder für Linux
```bash
sudo docker compose up
```
Falls für ihre Maschine keine Broker verfügbar sein sollte, ersetzen Sie folgende Einstellung in der .env Datei
```bash
     CELERY_TASK_ALWAYS_EAGER=True
```
Sie können die Seite nun unter

<http://127.0.0.1:8000/>

aufrufen

Der server kann gestoppt werden durch

```bash
docker compose down
```
oder für Linux
```bash
sudo docker compose down
```

## Administrations Panel
WeBus nutzt das Framework `django`.
> [!NOTE]
> Links werden im folgenden für die lokale Ausführung mit Port 8000 angegeben.
Ausgewählte Objekte können über folgende Adresse erstellt, verändert, gelesen und gelöscht werden.
`http://localhost:8000/admin/`

## Import und Export

Szenarien können als *json* exportiert und importiert werden.
Dies ist über diese Adresse möglich.
`
http://localhost:8000/simba/export/<UUID>/
`

Der Export ist für Szenarien möglich, welche fertig simuliert wurden, oder für Szenarien mit vollständiger Eingabe der Parameter des Wizards.
