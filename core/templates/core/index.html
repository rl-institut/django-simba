Features

Einfache Bedienung

Die Website leitet Sie Schritt-für-Schritt durch den Simulationsprozess. Eingansparameter werden ausführlich erläutert, Beispiele bereitgestellt und ein Tutorialvideo erklärt die Website in nur 10 Minuten. Experten-Wissen ist nicht notwendig.

Vielfältige Eingangsdaten

Es besteht die Möglichkeit Busfahrpläne in verschiedenen Formaten hochzuladen, z.B. als einfache .csv Tabelle, VDV-Konform als .x10 oder die Nutzung von Online-Fahrplänen, falls Ihnen keine Daten verfügbar sind.

Detaillierte Prozessmodellierung

Das Tool nutzt eine Vielzahl von Randbedingungen, die den Betrieb von elektrischen Fahrzeugen maßgeblich beeinflussen. Ladezeiten, Reinigung, Umparken, begrenzte Flächen, Ladekurven und vieles mehr werden berücksichtigt.

Elektrifizierungsstrategie

Sollte ein Bussystem im Ausgangszustand nicht elektrisch betrieben werden können, kann die Website prüfen, ob dies durch die Elektrifizierung von möglichst wenig Einzelhaltestellen möglich ist.

Kostenberechnung

Eine Kostenberechnung liefert Ihnen eine Abschätzung für die Total-Cost-of-Ownership und andere wichtige betriebswirtschaftliche Kennzahlen.

Visualisierung

Das simulierte Bussystem wird automatisch ausgewertet und visualisiert. So können in Kürze Aussagen über ein elektrifiziertes Bussystem getroffen und Entscheidungen abgeleitet werden.
